How to check it: on the physical snowflake, walk LED 1 to LED 25 on any one branch and confirm it matches the left panel. The right panel is that same branch rotated five more times (angles set in branch_angle_deg[]) with the 40×40 image grid drawn under it, exactly as build_led_positions() computes it in firmware.
Which layout a board uses is picked at build time with BRANCH_REVISION in main.c (BRANCH_REV_1 or BRANCH_REV_2). If a branch's twigs point the wrong way once flashed, it's branch_angle_deg[]; if the twigs themselves are the wrong shape, it's branch_led_pos[] for the active revision.
